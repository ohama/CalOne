- Always wrap localStorage operations in try-catch
- Use historyCache variable to avoid repeated localStorage reads
- Call renderHistory() after every mutation (add/clear)
- Return boolean from saveHistory() to indicate success
- Log warnings to console for storage errors, don't throw

**Do NOT:**
- Use eval() for any operations (security risk)
- Store on every button press (only completed calculations)
- Assume JSON.parse always works (wrap in try-catch)
