<task type="checkpoint:human-action" gate="blocking">
  <what-action>Configure GitHub Pages source in repository settings</what-action>
  <why-needed>GitHub Actions deployment requires repository Pages to be enabled with "GitHub Actions" as source. This setting cannot be changed via API or CLI - it requires web UI access.</why-needed>
  <instructions>
**Steps to configure GitHub Pages:**

1. Open repository in browser:
   - Navigate to https://github.com/[username]/cal (replace [username] with your GitHub username)

2. Go to Settings → Pages:
   - Click "Settings" tab at top of repository
   - Click "Pages" in left sidebar under "Code and automation"

3. Configure Build and deployment:
   - Under "Build and deployment" section
   - Find "Source" dropdown
   - Change from "Deploy from a branch" to "GitHub Actions"
   - Save (should auto-save when you select it)

4. Verify workflow completes:
   - Go to "Actions" tab in repository
   - You should see "Deploy to GitHub Pages" workflow running or completed
   - Wait for green checkmark (deployment usually takes 30-60 seconds)
   - Once complete, refresh the Settings → Pages page

5. Get deployment URL:
   - Settings → Pages will show "Your site is live at [URL]"
   - URL format: https://[username].github.io/cal
   - Copy this URL for verification step

**Common issues:**

- If workflow shows red X: Check workflow logs for errors
- If "GitHub Actions" not in Source dropdown: Ensure you have permissions to modify repository settings
- If deployment succeeds but site shows 404: Wait 1-2 minutes for DNS propagation, then hard refresh browser
  </instructions>
  <resume-signal>Type "configured" and paste the GitHub Pages URL when deployment is live</resume-signal>
</task>

**Common deployment issues:**

- **404 after deployment:** Wait 1-2 minutes, hard refresh (Ctrl+Shift+R)
- **JS modules not loading:** Check Network tab for MIME type errors (should be text/javascript)
- **Favicon not showing:** Browser cache issue - test in incognito mode
- **History not persisting:** localStorage blocked in private browsing - test in normal mode
</verification>
