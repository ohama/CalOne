Modify handleOperator() function in js/calculator.js to track completed calculations:

**Add before performCalculation() call when operator exists and nextOperator is '=':**

```javascript
// Track completed calculation for history (only binary operations)
if (nextOperator === '=' && calculator.operator && calculator.firstOperand !== null) {
  const expression = `${calculator.firstOperand} ${calculator.operator} ${calculator.displayValue}`;
  const result = performCalculation();

  // Only add to history if result is not an error
  if (result !== 'Error') {
    addToHistory(expression, String(result));
  }

  calculator.displayValue = String(result);
  calculator.firstOperand = result;
} else if (calculator.operator) {
  const result = performCalculation();
  calculator.displayValue = String(result);
  calculator.firstOperand = result;
}
```

**Important implementation notes from RESEARCH.md:**
- Only track binary operations (+, -, ×, ÷) when = is pressed
- Skip unary operations (%, +/-) as they're transformations, not calculations
- Don't track if result is 'Error' (division by zero)
- Call addToHistory BEFORE updating calculator state (so we capture the expression correctly)
- Use String(result) to ensure result is always a string for consistency

**Do NOT:**
- Track intermediate operations (only when = is pressed)
- Use eval() to build expressions (security risk)
- Store errors in history

**2. Add clear-history action to handleButtonClick switch:**

```javascript
function handleButtonClick(event) {
  const button = event.target.closest('button');
  if (!button) return;
  const { action, value } = button.dataset;
  switch (action) {
    case 'digit': inputDigit(value); break;
    case 'operator': handleOperator(value); break;
    case 'decimal': inputDecimal(); break;
    case 'clear': resetCalculator(); break;
    case 'backspace': handleBackspace(); break;
    case 'sign': toggleSign(); break;
    case 'percent': handlePercent(); break;
    case 'clear-history':
      if (typeof clearHistory === 'function') {
        clearHistory();
      }
      return; // Don't call updateDisplay for history clear
    default: return;
  }
  updateDisplay();
}
```

**Implementation notes:**
- Check if functions exist before calling (defensive programming)
- Clear history doesn't call updateDisplay() (doesn't affect calculator state)
- renderHistory() called on DOMContentLoaded to show persisted history from localStorage
- Reuse existing event delegation pattern for clear button
