<task type="auto">
  <name>Task 1: Create HTML button structure with semantic markup</name>
  <files>index.html</files>
  <action>
Replace the existing test harness HTML with a complete calculator button interface.

**Structure:**
1. Keep existing `<head>` metadata and update `<link>` to load `css/main.css` (to be created)
2. Replace `<body>` content with:
   - Calculator container with display area showing "0"
   - Button grid container with 19 buttons using semantic `<button>` elements
   - Each button has `type="button"` (prevents form submission)
   - Each button has `data-action` and `data-value` attributes for event delegation

**Button layout (4 columns × 5 rows):**
Row 1: AC, +/-, %, ÷
Row 2: 7, 8, 9, ×
Row 3: 4, 5, 6, -
Row 4: 1, 2, 3, +
Row 5: 0 (spans 2 columns), ., =

**Button attributes:**
- Digits (0-9): `data-action="digit"` `data-value="{digit}"`
- Operators (+, -, ×, ÷): `data-action="operator"` `data-value="{operator}"`
- AC: `data-action="clear"`
- +/-: `data-action="sign"`
- %: `data-action="percent"`
- .: `data-action="decimal"`
- =: `data-action="operator"` `data-value="="`

**Classes for styling:**
- `.calculator` - main container
- `.calculator-display` - display area (id="display" for JS access)
- `.calculator-buttons` - button grid container
- `.button` - base class for all buttons
- `.button-function` - AC, +/-, % buttons
- `.button-operator` - operator buttons (÷, ×, -, +, =)
- `.button-zero` - zero button (spans 2 columns)

Reference RESEARCH.md Code Examples section for complete HTML structure.

<task type="auto">
  <name>Task 2: Create CSS Grid layout with responsive design</name>
  <files>css/main.css</files>
  <action>
Create new CSS file with mobile-first responsive calculator styling.

**Mobile base styles (320px+):**
1. Body: center calculator, neutral background
2. `.calculator`: max-width 320px, box shadow, border-radius
3. `.calculator-display`: right-aligned text, 2.5rem font, padding, overflow handling (ellipsis), background #f0f0f0
4. `.calculator-buttons`: CSS Grid with `grid-template-columns: repeat(4, 1fr)`, 1px gap, background #999
5. `.button`: 60px height, 1.25rem font, cursor pointer, border none, background #e0e0e0, transition 0.15s
6. `.button-zero`: `grid-column: span 2`
7. `.button-function`: background #d0d0d0
8. `.button-operator`: background #ff9500, color white, font-weight 600
9. Button states:
   - `:active` - brightness(0.9), scale(0.98) for touch feedback
   - `:focus-visible` - 2px solid #007AFF outline for keyboard navigation
10. Wrap `:hover` in `@media (hover: hover) and (pointer: fine)` to prevent sticky hover on mobile

**Tablet styles (@media min-width: 768px):**
- `.calculator`: max-width 400px
- `.button`: height 80px, font-size 1.5rem
- `.calculator-display`: font-size 3rem

**Typography:**
- Use `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif` for buttons
- Use monospace variant for display

**Accessibility:**
- Remove tap highlight: `-webkit-tap-highlight-color: transparent`
- Ensure focus outlines are visible and clear

Reference RESEARCH.md "Responsive CSS Grid Layout" code example for complete styles.
