<task type="auto">
  <name>Create .nojekyll file and GitHub Actions deploy workflow</name>
  <files>

  </files>
  <action>
1. **Create .nojekyll** - Empty file that tells GitHub Pages to skip Jekyll processing:
   ```bash
   touch .nojekyll
   ```
   This prevents GitHub Pages from ignoring files/folders starting with underscore and improves deployment speed.

2. **Create .github/workflows/deploy.yml** - GitHub Actions workflow for automatic deployment:

Use the official GitHub Pages deployment pattern from research (05-RESEARCH.md):

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: "pages"
  cancel-in-progress: false

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v5

      - name: Setup Pages
        uses: actions/configure-pages@v5

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v4
        with:
          path: '.'

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

Key details:
- Triggers on push to main and manual workflow_dispatch
- Permissions: contents:read, pages:write, id-token:write (OIDC auth)
- Concurrency group prevents multiple simultaneous deployments
- Uses official actions: checkout@v5, configure-pages@v5, upload-pages-artifact@v4, deploy-pages@v4
- Uploads entire repository root (path: '.') - node_modules excluded by .gitignore
- Environment URL automatically captured from deployment output
  </action>
