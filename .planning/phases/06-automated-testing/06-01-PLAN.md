  <files>js/calculator.js, js/history.js, js/main.js, index.html</files>

    For each JavaScript file, add export statements at the end:

    calculator.js: export { calculator, inputDigit, inputDecimal, handleOperator, performCalculation, resetCalculator, toggleSign, handlePercent, handleBackspace, formatForDisplay }

    history.js: export { HISTORY_KEY, MAX_HISTORY_ENTRIES, loadHistory, saveHistory, addToHistory, clearHistory, renderHistory }

    - Change <script src="js/calculator.js"></script> to <script type="module" src="js/calculator.js"></script>
    - Same for history.js and main.js

    This preserves global scope behavior (functions still attach to window implicitly) while enabling ES module imports for tests.

    IMPORTANT: Modern browsers (2026) support ES modules natively. GitHub Pages serves these files correctly without build step.
  </action>
