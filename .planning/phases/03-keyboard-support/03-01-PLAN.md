  <action>
Add keyboard support by implementing a global keydown event listener that maps keyboard input to existing calculator functions.

**Implementation details:**

1. Create `handleKeyboardInput(event)` function in js/main.js that:
   - Checks `event.defaultPrevented` at start and returns early if true
   - Uses `event.key` property (not deprecated keyCode) to identify keys
   - Maps number keys ('0'-'9') to `inputDigit(event.key)`
   - Maps operator keys to calculator display symbols:
     - '+' → handleOperator('+')
     - '-' → handleOperator('-')
     - '*' → handleOperator('×')  // Map asterisk to multiplication symbol
     - '/' → handleOperator('÷')  // Map slash to division symbol
   - Maps special keys:
     - 'Enter' or '=' → handleOperator('=')
     - 'Escape' → resetCalculator()
     - 'Backspace' → handleBackspace()
     - '.' → inputDecimal()
   - Calls `event.preventDefault()` ONLY for handled keys (prevents browser back navigation on Backspace)
   - Calls `updateDisplay()` after handling each key
   - Returns early for unhandled keys without calling preventDefault()

2. Attach listener in DOMContentLoaded:
   - Add `document.addEventListener('keydown', handleKeyboardInput)` to initialization

**Pattern to follow (from RESEARCH.md):**
```javascript
function handleKeyboardInput(event) {
  if (event.defaultPrevented) return;

  let handled = false;

  // Numbers 0-9
  if (event.key >= '0' && event.key <= '9') {
    inputDigit(event.key);
    handled = true;
  }
  // Operators
  else if (['+', '-', '*', '/'].includes(event.key)) {
    const operatorMap = { '*': '×', '/': '÷' };
    handleOperator(operatorMap[event.key] || event.key);
    handled = true;
  }
  // Special keys
  else {
    switch (event.key) {
      case 'Enter':
      case '=':
        handleOperator('=');
        handled = true;
        break;
      case 'Escape':
        resetCalculator();
        handled = true;
        break;
      case 'Backspace':
        handleBackspace();
        handled = true;
        break;
      case '.':
        inputDecimal();
        handled = true;
        break;
    }
  }

  if (handled) {
    event.preventDefault();
    updateDisplay();
  }
}
```

**Why this approach:**
- Uses modern `event.key` property (not deprecated keyCode)
- Prevents browser default behavior only for handled keys
- Reuses all existing calculator functions (no duplication)
- Maps keyboard symbols to calculator display symbols (× and ÷)
- Checks `event.defaultPrevented` to avoid double-handling

**Anti-patterns to avoid:**
- DO NOT use deprecated `keyCode` or `keypress` event
- DO NOT call preventDefault() before checking if key is handled
- DO NOT attach listener to specific element (use document for global capture)
- DO NOT programmatically trigger button.click() (creates duplication with existing click handlers)
